Jobs and what drives them

Annual days = base + per agency × agencies + per 1,000 users × users / 1,000. "Per new agency" is one-off onboarding effort in the month an agency joins.

What does "Type" mean?

Type groups jobs by the kind of work, so you can see how much effort goes to running the service versus improving it. It is a label only: it does not change any cost or demand calculation.
